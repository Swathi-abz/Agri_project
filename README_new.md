# 🌾 AgriAI - AI Agricultural Advisory System

## Project Title
AI-Based Agricultural Advisory System for Multilingual Farmer Query Assistance

## Description
AgriAI is an AI-powered agricultural assistant that helps farmers by providing crop-related advice using Natural Language Processing, translation, and speech technologies.

## Features

- 🌱 Crop Advisory
- 🦠 Crop Disease Assistance
- 🌐 Multilingual Support
- 🎤 Speech-to-Text Processing
- 🔊 Text-to-Speech Response
- 🤖 AI Query Assistant
- 🌦 Weather Information
- 📈 Market Price Information

## Languages Supported

- English
- Telugu
- Kannada

## Technologies Used

Frontend:
- HTML
- CSS
- Bootstrap

Backend:
- Python
- Flask

AI/NLP:
- NLP Processing
- Language Detection
- Translation
- Speech Processing
